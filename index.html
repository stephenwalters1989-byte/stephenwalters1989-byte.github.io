Podcast Shorts Factory

A locally operated tool for creating podcast clips and managing uploads to Stephen Walters’s own YouTube channel.

What this installation does

The software transcribes source footage, selects excerpts, adds subtitles and prepares videos. With the channel owner’s permission, it uploads and schedules videos on YouTube and reads channel performance data to help assess future clips.

Why Google access is requested

Google authorisation connects the local application to the owner’s channel. Requested access covers video uploads, channel and video information, YouTube Analytics, and permissions capable of managing YouTube content and comments. Automatic comment posting is not currently configured.

This website is informational. It does not offer Google sign-in, accept video uploads or provide a service to other users.

About this app

This is Stephen Walters’s personal installation of the open-source Podcast Shorts Factory project. Stephen Walters operates this installation and is not the original software developer. This site is not affiliated with Google or YouTube.
